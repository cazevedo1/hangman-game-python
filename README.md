# Python Project - Jogo da Forca
    O seguinte projeto é o clássico Jogo da Forca porém desenvolvido usando Python.

## Funcionamento
    Passo 1: O jogo tem uma palavra constante no código.
    
    Passo 2: O jogador tem que adivinhar as letras contidas na palavra escondida, para isso ele tem 6 tentativas.
